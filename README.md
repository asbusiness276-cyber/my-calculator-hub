# My Calculator Hub (mycalculatorhub.pro)

Official production source code for **My Calculator Hub** ([https://mycalculatorhub.pro](https://mycalculatorhub.pro)) — a comprehensive web application featuring 260+ fast, accurate, client-side online calculators and 49 in-depth educational pillar calculation guides.

Deployed on **Vercel** (`my-calculator-hub-v2`).

---

## 🌟 Key Features

- **260+ Client-Side Calculators**:
  - **Financial**: SIP, EMI, PPF, GST, Salary to Hourly, Loan, Mortgage, 401(k), Retirement, Investment Return, Inflation, Net Worth, Credit Card Payoff.
  - **Academic & Grades**: Monash/Universal WAM, WAM to GPA (4.0 & 7.0 scales), CGPA, Final Grade Needed to Pass, Semester WAM, Honours Classification, Scholarship Eligibility.
  - **Health & Fitness**: BMI, BMR, TDEE, Calorie Maintenance & Deficit, Body Fat %, Macro Breakdown, Water Intake, Sleep Cycle, Blood Pressure.
  - **Daily Math & Utilities**: Percentage, Age, Date Difference, Time Zone, Word & Sentence Counter, Reading Time Estimator, Unit & Currency Converters.
  - **Science & Engineering**: Physics, Chemistry, Construction (Brick, Flooring, Paint, Concrete), Business (CAC, LTV, MRR, ARR, Margin, Markup).

- **49 Pillar Educational Guides & Articles**:
  - In-depth, formula-rich calculation guides written with high E-E-A-T standards.
  - Custom 16:9 featured artwork for all pillar articles.
  - Interactive contextual cross-linking between guides and calculation engines.

- **Design & UI**:
  - Modern, responsive Tailwind CSS styling with unique category-specific accent themes.
  - Mobile-first, fully responsive layouts with fast load times (sub-50ms TTFB via Vercel Edge Cache).

- **SEO & Technical Architecture**:
  - Next.js 15 App Router with full static site generation (SSG) for 370+ pre-rendered pages.
  - Clean Schema.org structured data (WebSite, SoftwareApplication, Article, FAQPage, BreadcrumbList).
  - Dynamic `sitemap.xml` and `robots.txt`.
  - Comprehensive 301/307 redirect mapping (`old-slugs.json`) for zero 404 broken links.
  - Google AdSense verified (`ads.txt`).

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/asbusiness276-cyber/my-calculator-hub.git
cd my-calculator-hub

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
npm run build
npm start
```
